# 인프라 일기 · 2026-11-18 · mycookie.dev 도메인 연결

> 캡처는 `docs/infra-diary/images/2026-11-18-domain/`에 로컬로만 보관합니다(이름 · 계정 정보가 보여 공개 저장소에 올리지 않음).

## 1. 도메인 고르기 (가비아)
- `devcookie.com`은 이미 등록됨. `cookies.dev`는 프리미엄이라 73만 원. → 01
- 예산 2만 원 이하로 다시 찾음. 첫해만 싸고 갱신비가 비싼 끝자리(.xyz 3,300원 → 33,000원, .store 2,200원 → 93,500원)는 제외.
- `cookie.*`, `cookies.*`는 거의 모두 등록됨. 최종 **mycookie.dev** (첫해 19,800원 / 갱신 31,900원, 1년) 구매. → 02
- 로그인 · 보안문자 · 결제는 직접 진행.

## 2. Vercel에 도메인 추가
- 프로젝트 cs-study-platform → Settings → Domains → **Add Existing**. → 03
- 기본으로 체크된 "Redirect apex domains to www (recommended)"를 **해제**. 대표 주소를 www가 아니라 `mycookie.dev`로 쓰기 위해서.
- `www.mycookie.dev`는 **Redirect to Another Domain → 308 Permanent Redirect → mycookie.dev**로 추가. → 04
- Vercel이 알려 준 DNS 값

| 타입 | 호스트 | 값 |
|---|---|---|
| A | @ | 216.198.79.1 |
| CNAME | www | ab4ff525e2604ef6.vercel-dns-017.com. |

## 3. 가비아 DNS 입력
- dns.gabia.com 목록의 오른쪽 **설정** 버튼은 반응이 없었다. → 05
  - 원인: 이 버튼은 포워딩 · 파킹 같은 *부가서비스* 설정이고, `.dev`처럼 HTTPS가 필수인 도메인은 부가서비스를 막아 둔다(경고창이 브라우저 창에서 보이지 않았음).
  - 해결: 도메인 **체크박스를 선택한 뒤 위쪽 "DNS 설정" 버튼**으로 레코드 화면에 들어간다. → 06
- A · CNAME 두 줄 입력 → 줄마다 **확인** → **저장**. → 07, 08

## 4. 확인
- 저장 직후 `nslookup`에서 바로 216.198.79.1로 조회됨(생각보다 빠름).
- Vercel에서 www는 Valid, 대표 주소는 "Generating SSL Certificate" → 1~2분 뒤 발급. → 09
- `https://mycookie.dev` 200, `https://www.mycookie.dev` → 308 → 대표 주소. 리뉴얼 안내 화면 정상 표시. → 10
