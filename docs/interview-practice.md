# 공통 면접 연습 (/interview)

인성면접은 사용자가 제공한 기본 17개, 직무/회사 13개, 개발 공통 19개, 총 49개로 전면 교체한다. `interviewPersonal.js`는 원문을 `original`에 보존하고 화면에는 면접관 존댓말로 다듬은 `text`를 표시한다. 기존 20개 질문은 출제하지 않는다. 질문 버전이 다르므로 별도 `personal-v2-*` ID를 사용한다.

기술면접은 전공노트 `CS_NOTES` 169개와 웹노트 `WEB_ESSENTIALS` 57개, 총 226개에서 출제한다. 별도 복제 은행 대신 기존 노트의 보정된 답변을 참조한다. 구술에 불필요한 Markdown과 코드 블록을 제외하고 존댓말로 정리하며, 학습 지시만 있던 항목과 표 중심 답변은 `interviewOral.js`에 별도 구술 답변을 작성했다. 상세 설명·코드와 공식 참고 자료는 원래 노트 링크에서 확인한다.

전체/노트/카테고리 필터, 무중복 랜덤 질문, 다음 질문, 출제 진행률, 소진 안내, 선택 범위 재시작을 제공한다. 출제 ID는 페이지 세션에서 유지하므로 필터와 모드를 바꿔도 이미 나온 질문을 반복하지 않는다. 재시작은 선택 범위의 출제 ID만 초기화한다. 답변은 처음에 접혀 있고 질문 변경 때 다시 접힌다. 인성 답변은 지원자의 경험이므로 일률적 모범 이력을 만들지 않고 답변 구성 안내를 제공한다.

웹노트의 `CsNotesPage.css`·`WebEssentialsPage.css` 목차·과목별 질문·접힌 답안 구조와 프로젝트 색상 토큰을 재사용한다. 맨 위에 랜덤 연습 영역을 두고 모드·노트·카테고리를 선택한다. 아래 질문 노트에서 ‘이 질문 연습’을 누르면 상단의 질문과 녹음 대상이 함께 바뀐다. 모바일에서는 한 열로 배치한다. 카메라 기능과 하단의 긴 출처·이용 조건 안내 영역은 사용자 요청으로 이 페이지에서 제거했다. 개별 문항의 원문과 원래 노트의 출처·이용 조건은 유지한다.

상단 녹음은 `InterviewAudio`의 선택적 `studio` 화면을 사용한다. 큰 마이크 시작 버튼, 실제 경과 시간과 최대 시간, 녹음 중 표시, 종료·다시 듣기·내려받기를 한 영역에 배치한다. 녹음·마이크 권한 대기·음성 인식 중에는 모드·필터·랜덤·다음·질문 선택을 막아 대상이 바뀌지 않도록 한다. AI 채점 은행과 ID가 다르므로 이 화면의 채점은 비활성화하며, 녹음·재생·내려받기와 사용자가 요청하는 음성 인식은 기존 기능을 사용한다. 다른 페이지의 공용 녹음 화면은 유지한다.

연습 흐름 참고: [Google Interview Warmup](https://blog.google/company-news/outreach-and-initiatives/grow-with-google/interview-warmup/), [Yoodli 연습 안내](https://support.yoodli.ai/en/articles/9550465-practice-with-yoodli). 질문을 보고 말한 뒤 다시 듣고 검토하는 흐름만 참고하고 화면·브랜드는 기존 프로젝트에 맞게 구성한다.

학습 기록: 원본 노트 ID, 계정 진도, 기존 localStorage 키, DB·서버 API·소유자 전용 자료는 변경하지 않는다. 출제와 녹음은 이 페이지 세션 안에만 보관하며 브라우저 저장소나 서버 진도에 쓰지 않는다. 새로고침·페이지 이동 시 출제 기록과 녹음이 초기화된다는 안내를 표시한다.

출처: ksundong 및 backend-interview-question 기여자의 기존 이식 문답을 사용한다. 원문은 CC BY-NC-SA라고 명시하면서 CC BY-NC 2.0 KR 링크도 제공한다. 프로젝트의 기존 출처 정책을 유지해 해당 이식·보완 문답에 저작자표시·비영리·동일조건 이용 조건을 적용하고, 질문별 원문과 변경 안내를 표시한다. 특정 버전을 단정하거나 웹노트 등 별도 작성 자료와 프로젝트 코드 전체로 이용 조건을 확대하지 않는다. 원문 고정본과 원래 노트는 변경하지 않는다.

검증: `npm run check:interview-practice`, `npm run check:interview-audio`, `npm run check:interview-camera`, 노트 관련 기존 검사, 변경 파일 ESLint, `npm run build`. 로컬 브라우저에서 데스크톱 및 390px 모바일의 필터·답안 표시와 가로 넘침을 확인한다. 운영 배포·병합은 수행하지 않는다.
